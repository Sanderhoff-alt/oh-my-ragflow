# Model platform extension

English | [简体中文](README.zh-CN.md)

Provide platform models to RAGFlow tenants while allowing them to use their own models. Platform model usage can be attributed and metered for future billing; tenant-owned model usage is not charged as platform usage.

**Status:** Design and implementation planning.

- [Architecture Design](architecture.md): Core invariant guarantees, system boundaries, and Architecture Decision Records (ADR 1~6).
- [Implementation Plan](implementation-plan.md): 25-task engineering roadmap across Phases 0~5, schema migrations, two-tier metering pipeline, and end-to-end integration verification guide.
